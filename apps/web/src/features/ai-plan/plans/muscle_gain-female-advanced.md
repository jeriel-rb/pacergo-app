# 增肌訓練 · 女性進階訓練計劃

> 每週五天推/拉/腿分化，臀腿高訓練量並運用遞減組與超級組強度技巧，最大化肌肥大。

## 進階方式
- 採波動式週期：第 1～3 週逐週增量（加重或加組），第 4 週減量恢復。
- 臀推、硬舉等主項用 8～10 下區間，每週設法多 1～2 下或加 2.5 公斤。
- 臀腿孤立動作引入遞減組、休息-暫停與超級組，提高代謝壓力與泵感。
- 下肢肌群週訓練量逐步推到 16～22 組，並監控恢復與表現。
- 每 8～12 週安排一週超補償（deload）週。

## 注意事項
- 強度技巧只用在孤立或機械動作末組，槓鈴大重量保留 1～2 RIR。
- 臀推、硬舉維持髖部鉸鏈與脊椎中立，避免以下背代償。
- 持續加量卻表現下滑、睡眠差、經期紊亂，是恢復不足訊號需減量。
- 高量離心控制（2～3 秒）以提升張力品質與肌肥大刺激。
- 睡足 7～9 小時並注意鐵質攝取，恢復與荷爾蒙平衡決定上限。

## 營養建議
進階女性採乾淨增肌，每日熱量盈餘控制在 150～300 大卡，避免脂肪過快堆積，目標每月增重約 0.3～0.5 公斤。蛋白質每公斤體重 2.0～2.4 公克，分 4～5 餐攝取以最大化肌肉蛋白合成，來源多元（瘦肉、魚、蛋、乳製品、豆類、乳清）。碳水隨訓練量浮動，腿日提高（3～5 公克／公斤）並集中於訓練前後補肝醣，休息日適度下調。脂肪維持總熱量 25～30%，重視 Omega-3 與荷爾蒙健康。每日補水 3～3.5 公升並補充電解質。特別留意鐵、鈣、維生素 D，並可搭配每日肌酸 3～5 公克及訓練前後乳清，定期依體態與經期狀況微調。
