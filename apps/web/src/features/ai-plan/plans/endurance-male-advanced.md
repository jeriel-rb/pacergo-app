# 耐力提升 · 男性進階訓練計劃

> 每週五天高度結構化：節奏跑、間歇、長距離與交叉訓練週期化堆疊，衝刺半馬與更高配速表現。

## 每週訓練安排
| 星期 | 訓練重點 | 時長/距離 |
| --- | --- | --- |
| 週一 | 輕鬆跑 + 核心 | 8K / 45 分鐘 |
| 週二 | 間歇（1000m × 5） | 約 12K |
| 週三 | 交叉訓練（飛輪/游泳） | 45–60 分鐘 |
| 週五 | 節奏跑（Tempo） | 10K |
| 週日 | 長距離跑（LSD） | 18–24K |

進階每週訓練 5 天，週四、週六休息或輕鬆動態恢復。維持「8 成輕鬆有氧、2 成高強度」結構，避免過度訓練。

## 動作菜單
**動態暖身** — 慢跑 1.5K + 動態伸展 + 4–6 趟 strides，10 分鐘。

- **輕鬆跑** — 配速約每公里 5:15–5:45，恢復與累積有氧里程。
- **間歇** — 1000m × 5 趟，以 5K 比賽配速（約每公里 4:10–4:20）執行，趟間慢跑 400m；亦可週期化換成 800m×6 或 400m×12。提升最大攝氧量與跑步經濟性。
- **節奏跑** — 在乳酸閾值配速（約每公里 4:40，半馬配速附近）持續 35–40 分鐘，或拆成 2×20 分鐘中間休 3 分鐘。
- **長距離跑** — 18–24K 輕鬆有氧配速（每公里 5:30 左右），最後 5K 可漸加速到馬拉松配速（progressive run）。
- **交叉訓練** — 飛輪、游泳或橢圓機 45–60 分鐘，無衝擊地補有氧量並分散下肢負荷；搭配核心與單腿肌力。

**收操** — 慢跑 8 分鐘 + 滾筒放鬆 + 全身靜態伸展。

## 進階方式
- 採 3 週進階、1 週減量的週期化，減量週總里程降 30%。
- 週里程增幅守住 10% 上限，逐步把巔峰週堆到 60–80K。
- 間歇先加總量再提配速；節奏跑時間與距離雙向漸進。
- 長跑每 2–3 週加 2K，並穿插「快結尾」或馬拉松配速段。
- 賽前 2–3 週開始減量（taper），保留強度、砍量約 40–50%。

## 注意事項
- 監測晨間靜止心率與睡眠，連續升高或疲勞不退是過度訓練警訊，立即減量。
- 高里程下每 500–700 公里輪替兩雙跑鞋，分散受力。
- 重視動態暖身與滾筒，預防跟腱、IT 束與足底高里程傷害。
- 善用心率/配速分區，確保輕鬆日真的輕鬆，別把恢復跑跑成中強度。

## 營養建議
高里程進階男性每日熱量約 3000–3600 大卡，碳水佔 55–65%，是肝醣與表現的關鍵燃料。長跑與間歇前一天起就「補碳」，當天提前 3 小時吃高碳水低纖維餐。長跑超過 90 分鐘每 30–40 分鐘補 60–90 克碳水（能量膠加電解質），訓練中持續小口補水並補鈉（每小時約 500–700 毫克）。跑後 30 分鐘內補碳水加蛋白質（約 3–4:1），蛋白質每公斤體重 1.8–2 克，分散到全天 4–5 餐維持修復。注意鐵與維生素 D，每日飲水 3500 毫升以上，依汗量與體重變化動態調整。
